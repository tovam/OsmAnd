# Flight airliner asset

- Source: [Funky aircraft](https://opengameart.org/content/funky-aircraft)
- Author: Savino
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Original high-detail OBJ: `https://opengameart.org/sites/default/files/high_0.obj`

Local changes: the model was assigned a black material. Smooth vertex normals were generated from
the original faces because OsmAnd's native OBJ loader requires explicit normals. The PNG is retained
only as a historical preview; the flight map renders the volumetric OBJ itself.
